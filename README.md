# Landing Quadribahia

Site estatico separado do sistema.

## Como testar local

Abra o arquivo `index.html` no navegador.

## Como hospedar no Render

Crie um Static Site separado apontando para esta pasta:

- Root Directory: `landing-quadribahia`
- Build Command: deixe vazio
- Publish Directory: `.`

Nao precisa de variaveis de ambiente.
